# マクロ

マクロは型を見ず、式・トークン・括弧による列の形と個数だけを使って機械的に展開する。

マクロはすべて名前を持つ。現在のモジュールまたは親モジュールで、それ以前に宣言されたマクロは自動的に使える。他モジュールのマクロは、インスタンス化済みの import に対して `\use` を宣言すると使える。

```text
\use arithmetic.plus_as_add;
```

同名のマクロを同時に可視にすることはできない。

マクロのパターンでは、`$name` が通常の式1個を捕捉する。`\+` のように `\` で始まるものは記号トークンであり、利用時には `\` を外す。`"tag"` は引用リテラルトークンである。予約済みの `:` や `:=` などは記号トークンにできない。

括弧内が通常の式として解析できる場合は式として扱い、そうでなければ入れ子のマクロ列として扱う。したがって複合式を1個の `$name` に渡す場合は括弧を付ける。

## 数式マクロ

数式マクロは `$( ... $)` 内で使う。

```text
\module MathMacroExample {
    \definition first(A: \Set(0)): A -> A -> A :=
        (left: A) => (right: A) => left;
    \math-macro plus_as_first($left, \+, $right) := first _ $left $right;

    \definition example(A: \Set(0), x: A, y: A): A := $(x + y $);
}
```

各括弧階層の列全体に一致するマクロだけが適用候補になる。一致候補が複数ある場合は、最も左に固定トークンを持つもの、その中では元の宣言順が早いものを選ぶ。

上の `plus_as_first` に対しては次のようになる。

- `$(x + y $)` は成功する。
- `$(x + y z $)` と `$(x + y + z $)` は、列全体が一致しないため失敗する。
- `$((x + y) + z $)` は、内側を先に展開するため成功する。

マクロの結果から、それ以前に可視だった別のマクロを呼び出すこともできる。展開深さが128を超えた場合はエラーになる。

## 名前付きマクロ

`name!{ ... }` は、その名前付きマクロだけを適用する。名前と `!` の間には空白を入れない。

```text
\module NamedMacroExample {
    \macro tagged($term, "keep") := $term;
    \definition example(A: \Set(0), value: A): A := tagged!{value "keep"};
}
```

こちらも入力列全体がパターンに一致しなければエラーになる。

マクロ本体の自由な識別子は宣言したモジュールで解決される。捕捉した式は呼出元で解決され、マクロ本体が導入する束縛変数に誤って捕捉されない。
