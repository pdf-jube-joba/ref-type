それ以外では、ともかく機械的な変換処理に徹する。
型を見て分岐はしない。
個数を見て分岐はあり。

マクロが使えるのは次のどれかのとき。
- そのモジュールか親のモジュールで定義された
- そのモジュール内で（他のモジュールの）定義を使用することを宣言した

あと、マクロの宣言には全て名前を付ける。
これで、使用するときに `use group_additive!` とかで `"+"` の使用が宣言できそう。

> [!warning]
> かっこの対応は最初から取り、 exp であるかどうかは判定する。
> つまり、 `atom = exp | token` に対して `m = atom | Vec<m>` を処理する。
> ただし、マクロの結果が他のマクロを参照してもいい。

## 数式用のマクロ
`$(` ~ `$)` の区間は数式用として宣言されたすべてのマクロを適用する。

> [!note]
> 最初に考えていた `$($ ここに何か入れる )` の案はなんか気持ち悪いのでやめる。

適用順は、非自明なトークンのうち一番左にあるものに適用可能なもののうち、一番早めに宣言されたもの。

```
\macro plus_as_add ($t1, \+, $t2) := add $t1 $t2;
```

`$` で始まるのが普通の exp で、 `\` で始まるのがマクロ用のトークン。
ただし、内部で使うときには `\` は落ちる。
`$(1 + 2$)` が `$($)`

## 専用の名前空間のマクロ
`name! { ... }` は指定されたマクロのみを使用する。
