# マクロ

マクロは型を見ず、式・トークン・括弧による列の形と個数だけを使って機械的に展開する。

マクロはすべて名前を持つ。現在のモジュールまたは親モジュールで、それ以前に宣言されたマクロは自動的に使える。他モジュールのマクロは、インスタンス化済みの import に対して `\use` を宣言すると使える。

```text
\use arithmetic.plus_as_add;
```

同名のマクロを同時に可視にすることはできない。

マクロのパターンでは、`$name` が通常の式1個を捕捉する。`\+` のように `\` で始まるものは記号トークンであり、利用時には `\` を外す。`"tag"` は引用リテラルトークンである。予約済みの `:` や `:=` などは記号トークンにできない。

マクロ内の `(...)` は常に入れ子のマクロ列として扱う。複合的な通常式を1個の `$name` に渡す場合は `{ f (g x) }` と書く。その内部の括弧は通常の式の括弧になる。識別子などの atom は直接渡せる。構文エラーをマクロ列として読み直すことはない。

## 数式マクロ

数式マクロは `$( ... $)` 内で使う。

```text
\module MathMacroExample {
    \definition first(A: \Set(0)): A -> A -> A :=
        \fun (left: A) => \fun (right: A) => left;
    \math-macro plus_as_first($left, \+, $right) := first _ $left $right;

    \definition example(A: \Set(0), x: A, y: A): A := $(x + y $);
}
```

各括弧階層の列全体に一致するマクロだけが適用候補になる。一致候補が複数ある場合は、最も左に固定トークンを持つもの、その中では元の宣言順が早いものを選ぶ。

上の `plus_as_first` に対しては次のようになる。

- `$(x + y $)` は成功する。
- `$(x + y z $)` と `$(x + y + z $)` は、列全体が一致しないため失敗する。
- `$((x + y) + z $)` は、内側を先に展開するため成功する。

マクロの結果から、それ以前に可視だった別のマクロを呼び出すこともできる。展開深さが128を超えた場合はエラーになる。

## 名前付きマクロ

`name!{ ... }` は、その名前付きマクロだけを適用する。名前と `!` の間には空白を入れない。

```text
\module NamedMacroExample {
    \macro tagged($term, "keep") := $term;
    \definition example(A: \Set(0), value: A): A := tagged!{value "keep"};
}
```

こちらも入力列全体がパターンに一致しなければエラーになる。

マクロ本体の自由な識別子は宣言したモジュールで解決される。捕捉した式は呼出元で解決され、マクロ本体が導入する束縛変数に誤って捕捉されない。

## 可変引数とトークンの捕捉

名前付きマクロでは、式の `$name` に加え、裸の名前で記号・引用トークン1個を、`..name` で残りの列を捕捉できる。式や括弧列は裸の名前では捕捉しない。

```text
\macro choose($left, tk, $right) :=
    \tmatch tk {
        | \+ => first;
        | "+" => second;
    } $left $right;
\macro forward($left, tk, ..r) := choose!{$left tk ..r};
```

この例では `first` と `second` は先に定義した関数とする。`forward!{x + y}` は `first x y`、`forward!{x "+" y}` は `second x y` に展開される。記号の `+` と引用トークンの `"+"` は別の値として照合される。

残りの捕捉は、各括弧階層のパターンの末尾に1個だけ置ける。0個以上の要素を捕捉し、式・トークン・入れ子の括弧列をそのまま保持する。`other!{..r}` は捕捉した列をその位置に挿入する。`r` だけでは残りの列を挿入しない。同じ列を複数回挿入することもできる。

捕捉したトークンは、別のマクロの入力列で `tk` と書いて渡す。通常の式中の `tk` は通常の識別子であり、`$tk` でトークンを式に変換することはできない。明示した `{ tk }` も通常の式として扱う。名前付きマクロ本体の `$(... $)` にも、トークンや残りの列を渡せる。

## 展開時の分岐と自己再帰

`\tmatch` は名前付きマクロの本体専用で、捕捉したトークンまたは列を照合し、選んだ枝の式を返す。各枝は `| パターン => 式;` と書く。トークンの照合には `\+` のような記号か引用トークンを使う。列の照合には、マクロ宣言と同じカンマ区切りのパターンを括弧で囲んで使う。

```text
\macro last(..r) := \tmatch r {
    | () => default_value;
    | ($t) => $t;
    | ($t, ..rest) => last!{..rest};
};
```

`default_value` は先に定義した式とする。`last!{}` はその値を返し、`last!{a b c}` は `c` を返す。`()` は対象の列が空であることを表し、`($t)` は式1個だけの列、`($t, ..rest)` は式1個と残りの列を表す。入れ子の括弧列を照合するには `(($t, ..rest))` のように書く。括弧列を自動的に平坦化することはない。

枝は上から照合し、最初の一致を使う。`_` はどの入力にも一致する既定の枝として使える。網羅性は要求せず、`_` も省略できる。空の `\tmatch tk {}` も宣言できる。実際の展開で一致する枝がなければエラーになる。

選ばれた枝だけを展開するため、終端の枝を選んだ場合は他の枝の再帰呼び出しを展開しない。ただし、捕捉名や自由な名前の検証は全ての枝に対して宣言時に行う。枝で捕捉した名前はその枝の本体だけで使え、外側の捕捉名との重複は許可しない。兄弟の枝は同じ捕捉名を使える。

名前付きマクロは自身を呼び出せる。それ以外は引き続き定義時点で可視だったマクロだけを呼べるため、後方参照や相互再帰はできない。再帰によって残りが減ることは静的に検証せず、展開深さの上限128で停止する。再帰中も、本体の束縛変数が捕捉した式の変数を誤って捕捉することはない。

数式マクロの宣言パターンにはトークン捕捉・残りの捕捉を追加せず、その本体では `\tmatch` を使えない。数式マクロの照合・候補選択規則は従来どおりである。
