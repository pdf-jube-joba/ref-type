# Reflection と変数

## 体系定義

### 構文定義

#### Sort

\[
\begin{aligned}
\mathcal S
&=
\{*^s_i,\sq^s_i\mid i\in\mathbb N\}
\cup\{*^p,\sq^p\}
\cup\{*^c,\sq^c\},\\
\mathcal A
&=
\{(*^s_i,\sq^s_i)\mid i\in\mathbb N\}
\cup\{(*^p,\sq^p),(*^c,\sq^c)\},\\
\mathcal R
&=
\mathcal R_{s,p}
\cup\{(*^c,*^c,*^c)\}.
\end{aligned}
\]

\(\mathcal R_{s,p}\) は `system.md` の Set/Prop product rule の集合である。

#### Variable

raw variable は name stem と sort annotation の組である。

\[
x^s\in\operatorname{Name}\times\mathcal S.
\]

従って \(x^{s_1}\) と \(x^{s_2}\) は、\(s_1\ne s_2\) なら異なる raw variable である。

\[
\begin{aligned}
\operatorname{FV}(t)
&\subseteq
\{x^s\mid x\in\operatorname{Name},\ s\in\mathcal S\},\\
\operatorname{Names}(V)
&:=
\{x\mid\exists s.\ x^s\in V\}.
\end{aligned}
\]

#### Context

\[
\Gamma
::=
\emptyset
\mid
\Gamma,x:T:s.
\]

\[
\begin{aligned}
\operatorname{dom}(\emptyset)&:=\emptyset,\\
\operatorname{dom}(\Gamma,x:T:s)&:=\operatorname{dom}(\Gamma)\cup\{x\}.
\end{aligned}
\]

context の freshness \(x\notin\Gamma\) は
\(x\notin\operatorname{dom}(\Gamma)\) の略記とする。

#### Term

`system.md` の term grammar に次が含まれる。

\[
\begin{aligned}
t::=\cdots
&\mid\operatorname{RunStep}(A,B)\\
&\mid\operatorname{continue}_{A,B}(a)
\mid\operatorname{finish}_{A,B}(b)\\
&\mid\operatorname{Acc}_{A,B}(f,a)\\
&\mid\operatorname{run}_{A,B}(f,a)\\
&\mid\operatorname{runCase}_{A,B}(f,a,u)\\
&\mid\operatorname{RfType}(A)\\
&\mid\operatorname{RfTerm}_A(m).
\end{aligned}
\]

`RfTerm` の source type annotation \(A\) と payload \(m\) は raw syntax の一部である。

#### 非依存 arrow

\[
A\to B
:=
(x^s:A)\to B
\qquad
(x^s\notin\operatorname{FV}(B)).
\]

#### 停止 predicate

\[
\begin{aligned}
\operatorname{continueFun}_{A,B}
&:=
\lambda z^{*^c}:A.\operatorname{continue}_{A,B}(z^{*^c})
:
A\to\operatorname{RunStep}(A,B),\\
\operatorname{Terminates}_{A,B}(f,a)
&:=
\operatorname{Acc}_{A,B}
\left(f,\operatorname{RfTerm}_A(a)\right),\\
\operatorname{RunInv}_{A,B}(f,a,u)
&:=
\operatorname{RfTerm}_{\operatorname{RunStep}(A,B)}(f@a)
=
\operatorname{RfTerm}_{\operatorname{RunStep}(A,B)}(u).
\end{aligned}
\]

### Reduction 定義

\(\Rightarrow\) は通常の Lambda 項の reduction と次の root rule の compatible closure とする。

#### subset

\[
\operatorname{Pred}(A,\{x:B\mid P\},t)
\Rightarrow
(\lambda x:B.P)@t.
\]

#### reflection

\[
\begin{aligned}
\operatorname{RfType}((x^{*^c}:A)\to B)
&\Rightarrow
(z^{*^s_0}:\operatorname{RfType}(A))
\to\operatorname{RfType}(B)
\qquad
\left(
  x^{*^c}\notin\operatorname{FV}(B),
  z\notin\operatorname{Names}(\operatorname{FV}(A)\cup\operatorname{FV}(B))
\right),\\
\operatorname{RfTerm}_{A\to B}(f)
@\operatorname{RfTerm}_A(a)
&\Rightarrow
\operatorname{RfTerm}_B(f@a).
\end{aligned}
\]

#### recursion

\[
\begin{aligned}
\operatorname{run}_{A,B}(f,a)
&\Rightarrow
\operatorname{runCase}_{A,B}(f,a,f@a),\\
\operatorname{runCase}_{A,B}
(f,a,\operatorname{continue}_{A,B}(a'))
&\Rightarrow
\operatorname{run}_{A,B}(f,a'),\\
\operatorname{runCase}_{A,B}
(f,a,\operatorname{finish}_{A,B}(b))
&\Rightarrow
b.
\end{aligned}
\]

#### Definitional equality

\[
\equiv
:=
(\Rightarrow\cup\Leftarrow)^*.
\]

### Judgement 定義

\[
\operatorname{WF}(\Gamma),
\qquad
\Gamma\vdash t:s,
\qquad
\Gamma\vdash t:T:s,
\qquad
\Gamma\vDash P.
\]

### Derivation 定義

#### `RunStep`

| --- | --- | --- |
| run step form | \(\Gamma\vdash\operatorname{RunStep}(A,B):*^c\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash B:*^c\) |
| continue intro | \(\Gamma\vdash\operatorname{continue}_{A,B}(a):\operatorname{RunStep}(A,B):*^c\) | \(\Gamma\vdash a:A:*^c\)<br>\(\Gamma\vdash B:*^c\) |
| finish intro | \(\Gamma\vdash\operatorname{finish}_{A,B}(b):\operatorname{RunStep}(A,B):*^c\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash b:B:*^c\) |

#### Accessibility

| category | conclusion | premises |
| --- | --- | --- |
| acc form | \(\Gamma\vdash\operatorname{Acc}_{A,B}(f,a):*^p\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash B:*^c\)<br>\(\Gamma\vdash f:A\to\operatorname{RunStep}(A,B):*^c\)<br>\(\Gamma\vdash a:\operatorname{RfType}(A):*^s_0\) |
| acc intro | \(\Gamma\vDash\operatorname{Acc}_{A,B}(f,a)\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash B:*^c\)<br>\(\Gamma\vdash f:A\to\operatorname{RunStep}(A,B):*^c\)<br>\(\Gamma\vdash a:\operatorname{RfType}(A):*^s_0\)<br>\(\Gamma\vDash\left((b:\operatorname{RfType}(A))\to\left(\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(f)@a=\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(\operatorname{continueFun}_{A,B})@b\right)\to\operatorname{Acc}_{A,B}(f,b)\right)\) |
| acc descent | \(\Gamma\vDash\operatorname{Acc}_{A,B}(f,b)\) | \(\Gamma\vDash\operatorname{Acc}_{A,B}(f,a)\)<br>\(\Gamma\vDash\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(f)@a=\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(\operatorname{continueFun}_{A,B})@b\) |

#### Reflection

| category | conclusion | premises |
| --- | --- | --- |
| reflection type | \(\Gamma\vdash\operatorname{RfType}(A):*^s_0\) | \(\Gamma\vdash A:*^c\) |
| reflection term | \(\Gamma\vdash\operatorname{RfTerm}_A(m):\operatorname{RfType}(A):*^s_0\) | \(\Gamma\vdash m:A:*^c\) |

#### `run`

| category | conclusion | premises |
| --- | --- | --- |
| run | \(\Gamma\vdash\operatorname{run}_{A,B}(f,a):B:*^c\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash B:*^c\)<br>\(\Gamma\vdash f:A\to\operatorname{RunStep}(A,B):*^c\)<br>\(\Gamma\vdash a:A:*^c\)<br>\(\Gamma\vDash\operatorname{Terminates}_{A,B}(f,a)\) |
| run case | \(\Gamma\vdash\operatorname{runCase}_{A,B}(f,a,u):B:*^c\) | \(\Gamma\vdash A:*^c\)<br>\(\Gamma\vdash B:*^c\)<br>\(\Gamma\vdash f:A\to\operatorname{RunStep}(A,B):*^c\)<br>\(\Gamma\vdash a:A:*^c\)<br>\(\Gamma\vdash u:\operatorname{RunStep}(A,B):*^c\)<br>\(\Gamma\vDash\operatorname{Terminates}_{A,B}(f,a)\)<br>\(\Gamma\vDash\operatorname{RunInv}_{A,B}(f,a,u)\) |

## `Acc`

集合 \(X\) 上の二項関係 \(R:X\to X\to *^p\) に対し、accessibility は次の closure で
帰納的に生成される最小の predicate である。

\[
\left(
  (b:X)\to R@b@a\to\operatorname{Acc}_X(R,b)
\right)
\to
\operatorname{Acc}_X(R,a).
\]

今回の一段関数 \(f:A\to\operatorname{RunStep}(A,B)\) が reflected state 上に誘導する関係を
\(R_f\) と書く。

\[
\begin{aligned}
R_f
&:
\operatorname{RfType}(A)
\to
\operatorname{RfType}(A)
\to *^p,\\
R_f@b@a
&:=
\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(f)@a
=
\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}
(\operatorname{continueFun}_{A,B})@b.
\end{aligned}
\]

体系の \(\operatorname{Acc}_{A,B}(f,a)\) は、この場合だけに限定した
\(\operatorname{Acc}_{\operatorname{RfType}(A)}(R_f,a)\) である。

## Variable を含む glued form

通常の variable rule は

\[
\dfrac{
  \operatorname{WF}(\Gamma,x:T:s)
}{
  \Gamma,x:T:s\vdash x^s:T:s
}
\tag{Var}
\]

である。Compute variable に対しても、この rule から

\[
\Gamma,x:A:*^c
\vdash
x^{*^c}:A:*^c
\]

を得る。従って Rf-Term により

\[
\Gamma,x:A:*^c
\vdash
\operatorname{RfTerm}_A(x^{*^c})
:
\operatorname{RfType}(A):*^s_0
\]

を導ける。

\(\operatorname{RfTerm}_A(x^{*^c})\) は \(x^{*^s_0}\) には reduce せず、neutral な glued form
として残る。payload の \(x^{*^c}\) は、元の Compute context entry によって bind される。

型変数についても、通常の variable rule から

\[
\Gamma,X:*^c:\sq^c
\vdash
X^{\sq^c}:*^c:\sq^c
\]

を得て、Rf-Type により

\[
\Gamma,X:*^c:\sq^c
\vdash
\operatorname{RfType}(X^{\sq^c}):*^s_0
\]

を導く。\(\operatorname{RfType}(X^{\sq^c})\) も neutral な form として残る。

context entry \(\Gamma,x:T:s\) が bind する raw variable は \(x^s\) だけであり、annotation の
異なる variable を導く特殊な variable rule は置かない。

## Substitution

substitution は full raw variable に対する通常の capture-avoiding substitution とする。
reflection form に対しては source type annotation と payload の両方へ入る。

\[
\begin{aligned}
\operatorname{RfType}(A)[x^s:=n]
&:=
\operatorname{RfType}(A[x^s:=n]),\\
\operatorname{RfTerm}_A(m)[x^s:=n]
&:=
\operatorname{RfTerm}_{A[x^s:=n]}(m[x^s:=n]).
\end{aligned}
\]

例えば

\[
\operatorname{RfTerm}_A(x^{*^c})[x^{*^c}:=a]
=
\operatorname{RfTerm}_{A[x^{*^c}:=a]}(a).
\]

context formation により \(x:A:*^c\) の \(A\) は \(x\) を含まないため、

\[
\operatorname{RfTerm}_A(x^{*^c})[x^{*^c}:=a]
=
\operatorname{RfTerm}_A(a)
\]

となる。型変数についても

\[
\operatorname{RfType}(X^{\sq^c})[X^{\sq^c}:=C]
=
\operatorname{RfType}(C)
\]

である。sort annotation の異なる variable を同時に置換する paired substitution は用いない。

## Function type の reflection

型変数の reflection は neutral に保つが、Compute function type の reflection は application
のために分解する。

\[
\operatorname{RfType}((x^{*^c}:A)\to B)
\Rightarrow
(z^{*^s_0}:\operatorname{RfType}(A))
\to
\operatorname{RfType}(B).
\tag{Rf-Arrow}
\]

ここで

\[
x^{*^c}\notin\operatorname{FV}(B)
\]

は Compute product の非依存性であり、

\[
z\notin
\operatorname{Names}(\operatorname{FV}(A)\cup\operatorname{FV}(B))
\]

は target binder の freshness condition である。target binder は新しい name stem \(z\) を使うので、
Compute variable の sort annotation を付け替える操作はない。

この rule により

\[
\operatorname{RfTerm}_{A\to B}(f)
:
\operatorname{RfType}(A)\to\operatorname{RfType}(B)
\]

が definitional equality を介して成り立つ。従って通常の application と

\[
\operatorname{RfTerm}_{A\to B}(f)
@\operatorname{RfTerm}_A(a)
\Rightarrow
\operatorname{RfTerm}_B(f@a)
\tag{Rf-App}
\]

の双方が type-correct になる。

## \(R_f\) での variable

\(R_f\) の引数 \(a,b\) は \(\operatorname{RfType}(A)\) 上の通常の Set 項である。

function type の reflection が分解されるため、両辺の application は well-typed である。
\(a\) と \(b\) が未置換の間は application は neutral に残る。reflected state を代入した後は、
例えば

\[
\begin{aligned}
&\left(
  \operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(f)@a
\right)
[a:=\operatorname{RfTerm}_A(a_0)]\\
&\qquad=
\operatorname{RfTerm}_{A\to\operatorname{RunStep}(A,B)}(f)
@\operatorname{RfTerm}_A(a_0)\\
&\qquad\Rightarrow
\operatorname{RfTerm}_{\operatorname{RunStep}(A,B)}(f@a_0)
\end{aligned}
\]

と Rf-App が適用される。従って RunCase-Continue の subject reduction に variable reflection は
必要ない。

## Binding と alpha-equivalence

context entry \(\Gamma,x:T:s\) は \(x^s\) を bind する。context の freshness は name stem に
よって判定し、substitution と alpha-renaming は full raw variable に対して行う。

\(\operatorname{RfType}\) と \(\operatorname{RfTerm}\) は binder ではない。substitution と
alpha-renaming はそれぞれの argument、source type annotation、payload に入る。Rf-Arrow の
target binder \(z^{*^s_0}\) は fresh に選ぶため、Compute binder と同期した alpha-renaming は
発生しない。

## この構成で残る reflection rule

reflection に必要な rule は次の四つである。

- Rf-Type
- Rf-Term
- Rf-Arrow
- Rf-App

Compute の term variable と type variable はそれぞれ
\(\operatorname{RfTerm}_A(x^{*^c})\) と
\(\operatorname{RfType}(X^{\sq^c})\) のまま neutral に残る。

## 確認する補題

- Rf-Type と Rf-Term に対する substitution lemma
- Rf-Arrow の subject reduction と freshness
- Rf-App の subject reduction
- Rf-App と compatible closure の critical pair
- \(\operatorname{RunInv}\) と \(\operatorname{Terminates}\) の substitution による保存
- Acc-Intro と Acc-Descent の substitution による保存
- Compute product の非依存性
- sort separation
