# マクロ

マクロは式・トークン・括弧による列の形と個数だけを使って機械的に展開するだけ。

- 自分かその親のモジュールで定義されていたら自動で使える。
- 他のところから使うには(インスタンス化して) import する: 今の構文は `\use moduleName.macroName`
  - これのために、全てのマクロ定義は名前を持つ。
  - 同名のマクロを同時に可視にすることはできない。

## マクロ定義時の共通仕様
マクロ書くときにマッチするトークンを書くためのパターン
- `$name` が通常の式1個
- `\` で始まるものは記号トークン
  - 利用時には `\` を外したものが対応する。
- `"tag"` は引用リテラルトークン
- 予約済みの `:` や `:=` などは記号トークンにできない。
- マクロ内の `(...)` は常に入れ子のマクロ列として扱う。
  - 識別子などの atom は直接渡せる。
  - 複合的な通常式を1個の `$name` に渡す場合は `{ f x }` のように `{` ~ `}` に入れる。その内部の括弧は通常の式として解釈を始める。

## 数式マクロ
数式マクロは、コンテキストをごっちゃにして一つの式で現すとき用。

数式マクロは `\( ... \)` 内で使う。

```text
\module MathMacroExample {
    \use arith.multiple; /* これは `a * b` とかの定義をしているとする。 */
    \definition first(A: \Set(0)): A -> A -> A :=
        \fun (left: A) => \fun (right: A) => left;
    \math-macro plus_as_first($left, \+, $right) := first _ $left $right;

    \definition example(A: \Set(0), x: A, y: A): A := \(x + y \);
}
```

各括弧階層の列全体に一致するマクロだけが適用候補になる。一致候補が複数ある場合は、最も左に固定トークンを持つもの、その中では元の宣言順が早いものを選ぶ。

上の `plus_as_first` に対しては次のようになる。

- `\(x + y \)` は成功する。
- `\(x + y z \)` と `\(x + y + z \)` は、列全体が一致しないため失敗する。
- `\((x + y) + z \)` は、内側を先に展開するため成功する。
- `\((x + y) * z\)`, `\((x * y) + z\)` ... ok

マクロの結果から、それ以前に可視だった別のマクロを呼び出すこともできる。

展開深さが \(128\) を超えたらエラーにする。

## 名前付きマクロ
どのマクロを使うかを明らかにする（これは rust のマクロっぽい感じ）。
数式マクロよりも複雑なことをする用。

```text
\module NamedMacroExample {
    \macro tagged($term, "keep") := $term;
    \definition example(A: \Set(0), value: A): A := tagged!{value "keep"};
}
```

マクロの名前と `!` の間には空白を入れない。

マクロ本体の自由な識別子は宣言したモジュールで解決される。捕捉した式は呼出元で解決され、マクロ本体が導入する束縛変数に誤って捕捉されない。

- `$` をつけない変数は記号トークン・引用トークンを1つ捕捉する。
- `..name` で残りの列を捕捉する。(0個もあり)
  - トークン列そのまま展開する感じ。
- `\tmatch` でマッチに対する分岐をする。

```text
// この例では `first` と `second` は先に定義した関数とする。
\macro choose($left, tk, $right) :=
    \tmatch tk {
        | \+ => first
        | "+" => second
    } $left $right;
\macro forward($left, tk, ..r) := choose!{$left tk ..r};
```

- `forward!{x + y}` は `first x y` になる
- `forward!{x "+" y}` は `second x y` になる。

## 展開時の分岐と自己再帰

`\tmatch` は名前付きマクロの本体専用で、捕捉したトークンまたは列を照合し、選んだ枝の式を返す。各枝は `| パターン => 式` と書き、次の `|` または `}` で区切る。トークンの照合には `\+` のような記号か引用トークンを使う。

```text
// `default_value` は先に定義した式とする。
\macro last(..r) := \tmatch r {
    | () => default_value
    | ($t) => $t
    | ($t, ..rest) => last!{..rest}
};
```

`..r` は、各括弧階層のパターンの末尾に1個だけ置ける。

- `last!{}` は `default_value` ... `()` は対象の列が空のときにマッチする。
- `last!{a}` は `a` ... 式が1つなので `($t)` にマッチする。
- `last!{a b}` は `last!{b}` になって `b` になる。`last!{a b c}` は最終的に `c` ... これらは残りの列に

> [!warning]
> 括弧列を自動的に平坦化することはない。

枝は上から照合し、最初の一致を使う。
`_` はどの入力にも一致する既定の枝として使える。
網羅性は要求せず、`_` も省略できる。
空の `\tmatch tk {}` も宣言できる。
実際の展開で一致する枝がなければエラーになる。

選ばれた枝だけを展開するため、終端の枝を選んだ場合は他の枝の再帰呼び出しを展開しない。ただし、捕捉名や自由な名前の検証は全ての枝に対して宣言時に行う。枝で捕捉した名前はその枝の本体だけで使え、外側の捕捉名との重複は許可しない。兄弟の枝は同じ捕捉名を使える。

名前付きマクロは自身を呼び出せる。それ以外は引き続き定義時点で可視だったマクロだけを呼べるため、後方参照や相互再帰はできない。再帰によって残りが減ることは静的に検証せず、展開深さの上限128で停止する。
