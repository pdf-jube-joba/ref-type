# Lean 形式化の方針

方針は `doc/book/src/system.md` を正本とし、それと導出可能性が同値な
`RefType.System.Derives` presentation にモデルを与えること。

- `system.lean` は `doc/book/src/system.md` の実装候補であり、既知の presentation の差は
  `formalization.md` 1.1節に従って解消する。
- consistency 証明では別の構文体系を経由しない。
- Lean 内で first-order logic や ZFC は定義しない。
- 集合論的 universe 仮定に相当する部分は `System.UniverseTower` という
  Lean の `structure` としてまとめる。
- soundness は `UniverseTower` の field にはせず、raw reduction の confluence、
  sorting / typing / provability subject reduction、導出依存意味論から証明する。
- original の `typeConv` は raw `BetaEq` のまま維持する。証明時だけ WF、regularity、
  typed join diagram を保持する `DerivesPlus : Context -> Sequent -> Type` へ
  elaboration し、rank に関する強い帰納法で soundness と意味保存を同時に示す。

自然言語の証明は `proof.md`、Lean への対応は `formalization.md`、実装タスクは
`../TODO.md` を参照する。
