# 比較結果の保存

比較ごとにディレクトリを作り、`bench.py` が出力した `before.json` と `after.json`、実行条件と結果の説明をまとめる。
ケース名と入力、繰り返し数、計測対象、キャッシュの条件、資源制限を揃える。
実行したコマンド、比較する revision、ビルド条件を説明に含める。

```text
records/
  <比較名>/
    README.md
    before.json
    after.json
```

レポートにはバイナリとソースの digest、実際のコマンド、終了状態、各回の計測値と成功した実行の集計が含まれる。
レポート全体の `complete` と各回の `completed` を確認し、同じ条件の結果を比べる。
詳細計測は通常の繰り返しと分け、profile の環境変数も揃える。
ログや一時データは `runs/` に置き、説明には比較に必要な観測を記述する。

[大規模検査の宣言共有と継続実行](large-scale-checking/README.md) は、原形とview、式のページ化、長寿命worker、保存と復旧の比較記録である。
