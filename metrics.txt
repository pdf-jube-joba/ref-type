ref-type performance metrics
============================

Measurement procedure
---------------------

Run all commands from the repository root.

Build the executable before each measurement. The build itself is not measured.

    cargo build --release

Record the measurement metadata.

    while true; do
      measurement_prefix=$(date +%Y%m%d-%H%M%S-%N)
      if [[ ! -e "data/${measurement_prefix}-perf.data" \
         && ! -e "data/${measurement_prefix}-flamegraph.svg" ]]; then
        break
      fi
    done
    echo "$measurement_prefix"
    date --iso-8601=seconds
    git rev-parse HEAD
    rustc --version
    perf-wsl --version

Run the benchmark three times with the same executable, input, and output redirection.

    for run in 1 2 3; do
      /usr/bin/time \
        -f "run=$run elapsed_seconds=%e max_rss_kb=%M" \
        target/release/cli file tests/reals/root.ref \
        >/dev/null
    done

When recording sampled call stacks, prefix output names with the measurement timestamp.

    perf-wsl record \
      -F 99 \
      -g \
      --call-graph dwarf,16000 \
      -o "data/${measurement_prefix}-perf.data" \
      -- target/release/cli file tests/reals/root.ref \
      >/dev/null

Report functions with at least 1% self overhead.

    perf-wsl report \
      --stdio \
      --no-children \
      -g none \
      --sort overhead,symbol \
      --percent-limit 1 \
      -i "data/${measurement_prefix}-perf.data" \
      | c++filt

Report the top twenty kernel functions by inclusive overhead.

    perf-wsl report \
      --stdio \
      --children \
      -g none \
      --sort overhead_children,symbol \
      --percent-limit 0 \
      -i "data/${measurement_prefix}-perf.data" \
      | rg 'kernel::(calculus|derivation)' \
      | head -n 20

Generate a flame graph from the same recording.

    PERF=/usr/local/bin/perf-wsl \
    flamegraph \
      --perfdata "data/${measurement_prefix}-perf.data" \
      --deterministic \
      --title 'ref-type tests/reals/root.ref' \
      -o "data/${measurement_prefix}-flamegraph.svg"

Append the metadata, timing output, recording summary, and report tables below. Do not add interpretations to this file.
