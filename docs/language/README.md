# Language reference

This directory documents the implemented language separately from the [calculus and design book](../book/src/SUMMARY.md).

- [Surface syntax](syntax.md): lexical rules, modules, declarations, expressions, proofs, Program, and execution.
- [Type-associated items and projections](types_and_items.md): constructors, associated definitions, aliases, and record projections.
- [Structures](structure.md): declaration bundles, records, defaults, and quantification.
- [Macros](macro.md): patterns, scope, hygiene, token matching, and recursion.
- [Implementation](implementation.md): crate responsibilities and checking sessions.

See [CLI usage](../../src/USAGE.md) for commands and package configuration, and [source tests](../../tests/README.md) for executable acceptance and rejection examples.
