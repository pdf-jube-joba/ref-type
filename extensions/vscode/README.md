# Ref Type for VS Code

`.ref` ファイルの診断、定義への移動、型とゴールのホバー表示、参照検索に対応します。
同梱の LSP サーバーを使います。
別の実行ファイルを使う場合は `ref.server.path` を指定します。
LSP は CLI と同じ `refcache/` の検証結果を再利用します。
`ref.toml` の `[workspace].packages` に属する package は workspace ルートのキャッシュを共有し、その他の package は自身のディレクトリ、単独のソースはソースルートのキャッシュを使います。
VS Code で開いたフォルダーやサーバーの起動ディレクトリにかかわらず、文書ごとに保存先を判定します。
保存前の編集や依存ファイルの変更は再検査し、有効なキャッシュがなければソースから検査します。
コマンドパレットの「Ref: Reload Database」で言語サーバーを再起動し、解析データベースを作り直せます。
