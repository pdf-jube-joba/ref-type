# Package の仕様
rust っぽい方向かつ `.lock` はなしの方向にする。

```ref.toml
[package]
name = "real"

[dependencies]
std = { path = "../std" }
```

- `./ref.toml` にパッケージ情報、 `./src/` にコード、 `./src/root.ref` がコードのエントリポイントとする。必要に応じて `./ref_cache/` に永続キャッシュをメモするファイルを置く。
- version 周りは入れないが、将来的に入れることを見越して内部的には Name ではなくて Id を見るようにする。
- 参照先は path のみとする。 `git = { ... }` とかの方向はなし。 `path = { ... }` のみ。
- 他のパッケージをコード中で参照するときは、 `otherPackageName.moduleName[]` とする。
  - 現状の子 module を import するときの `Child[].Descendant[]` という書き方はやめて、一番初めに `.` をつける。

```
\import .Child[].Descendant[] \as Loc; // これは自分の子モジュール
\import Other.Descendant[] \as Loc; // これは他のパッケージ `Other` の module の参照。
```

## 現在のコードを package 化する。
- `libs/` という名前にする。
- `libs/std/`, `libs/real/`, `libs/topology/` にわけてそれぞれパッケージにする。

# コードの話
- crate を分けたいという話だったのがプランから消えてたのに気が付かなかった。とりあえず crate 分割をしてほしい。
- visibility は一旦無視して実装する。他のパッケージの宣言は全部見えるようにしておく。
- あと、 LSP/MCP などの **基盤** を実装してほしくて、 LSP/MCP を実装してほしいわけじゃなかった。削除してほしいわけじゃないが、これ以上はそういう基盤上の何かを実装しないようにしてほしい。（開発する上で保守する機能が増えるので。）
- ソースコードを正として、永続キャッシュは高速化のための中間にしたい。変更がなかったら状態をキャッシュから復元して検査をスキップしたりなどをしたい。永続キャッシュは宣言ごとにする。
- inductive の定義でコンストラクタごとに `;` を使っているのをやめれば、宣言の始まりから終わりまでをかなり楽に判定できるようになりそうなので、そこも変えておく。
