# B06 束の分類写像と安定化

## 要件

- 主な実装先は `bundle_classification`。
- コンパクト Hausdorff 底空間上の束に有限 Grassmannian への分類写像を構成する。
- 分類写像の選択独立性と、周囲次元を十分大きくしたときのホモトピー類と束同型類との全単射を証明する。
- 実の向き付き束と枠付き束の分類にも拡張し、底空間の写像・直和・安定化に対する自然性を公開する。

## 実装

実装は [bundle_classification](../../libs/geometry/bundle_classification/README.md) にある。

- 実・複素束の有限 Grassmannian への連続分類写像と普遍束の引き戻しへの比較同型。
- 成分ごとに階数が変わる束の、有限次元空間内の全階数の射影族による分類。
- 埋め込みの補間による選択独立性、安定化射影ホモトピーと束同型の同値、両者の類の全単射。
- 実の向き付き束の行列式余接線の正の半直線による分類と、向きを保つホモトピー分類。
- 枠付き束の有限 Stiefel 分類写像と安定化ホモトピー。
- 引き戻し・直和・自明束の付加との自然性、最小利用例。

追加の公開 API として、枠付き分類の商上の直和・安定化と分類 API との可換性、および与えた直和束の向きを比較同型に沿って輸送した場合の分類との可換性を実装した。
向き付き直和の比較は直和束全体に与えた向きを入力に取り、因子の向きから標準の積向きを作る行列式テンソル積同型は含まない。

通常検査の条件と結果は [検査記録](../../benchmarks/records/bundle-classification/README.md) に記載する。
